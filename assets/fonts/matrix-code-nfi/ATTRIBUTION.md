# Matrix Code NFI

- **Font family:** `Matrix Code NFI`
- **Author:** Norfok Incredible Font Design
- **File:** `MatrixCodeNFI.ttf`
- **License:** see [`LICENSE.txt`](./LICENSE.txt) (free for display use)

The film's mirrored-katakana "digital rain" glyphs are mapped onto ASCII
letters and digits, so the matrix tab-switch transition shapes plain ASCII in
this font to draw the falling stream (see
`wezterm-gui/src/termwindow/render/matrix_rain.rs`).

Embedded as a built-in font in `wezterm-font/src/parser.rs` so it resolves by
family without any user configuration.
