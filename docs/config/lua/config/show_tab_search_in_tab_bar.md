# `show_tab_search_in_tab_bar = true`

{{since('nightly')}}

When `true` (the default) a `⌕ search` box is drawn at the right end of a
horizontal tab bar; clicking it opens the tab search dropdown, as
[ShowTabSearch](../keyassignment/ShowTabSearch.md) does from the keyboard.
With a Left/Right bar the box sits in the child row across the top.

Set to `false` to leave it out. The key binding still works.
